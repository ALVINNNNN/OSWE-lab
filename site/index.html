YOUR WORKSPACE / ABOUT 5 MINUTES AFTER DOCKER IS INSTALLED

Start with Docker Compose

You need Git and Docker with Compose. These commands work from a terminal on Windows, macOS, or Linux. The first build downloads the container images.

git clone https://github.com/ALVINNNNN/OSWE-lab.git
cd OSWE-lab
docker compose up --build -d

Wait for the targets to become healthy with docker compose ps, then open a local target above. Each peer runs their own copy. This website is the catalogue; it does not provision hosted instances.

Reset one target: docker compose restart recovery
Stop everything: docker compose down

Make the finding yours

01 / Investigate

Read the source and capture a normal request first. Use the progressive hints only when you need them.

02 / Prove it

Write a repeatable script, recover your instance's flag, and verify it in the target UI.

03 / Remediate

Patch the trust boundary. Use the supplied patched mode as a reference and check that normal behavior still works.
